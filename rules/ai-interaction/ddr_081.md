# Keep completed tool images visible outside collapsed output

In bb timelines, images emitted by tool output should remain visible after a turn completes, without requiring the user to expand the tool-output rollup.

## Why

Collapsing tool details should not hide the image results the user needs to see.

## Prefer

- Show completed tool-output images as visible timeline content outside the rollup.
- Preserve image order while retaining expandable tool text.

## Avoid

- Making users expand a completed tool-output rollup to see its images.

## Use when

- Presenting tool output containing images in completed bb turns.

## Do not use when

- Deciding how in-progress tool output should behave.
- Designing presentation for non-image tool results.

## Evidence

- The user requested that tool-output images remain visible after completion without expanding the rollup.

## Check

- With a completed turn collapsed, are its tool-output images visible?
- When several images are present, does their displayed order remain intact?
