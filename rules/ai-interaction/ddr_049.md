# Treat Handoff as an explicitly declared transfer

In the user's BB organizer, move a thread to Handoff only when the user explicitly declares handing it to a colleague to finish.

## Why

The user owns the intent to transfer work; agents repeatedly inferred that intent incorrectly.

## Prefer

- Clear agent-facing rules requiring an explicit user declaration

## Avoid

- Inferring Handoff from work progress or readiness
- Introducing a new user-controlled-section mechanism solely to enforce this preference

## Use when

- Deciding whether to move a thread into the user's Handoff section

## Do not use when

- Defining unrelated users' workflow sections or other workflow stages

## Evidence

- The user said Handoff means handing a thread to a colleague to finish, and requested clearer agent rules rather than a new restricted-section concept.

## Check

- Has the user explicitly declared the handoff?
- Do the section rules communicate that requirement clearly?
