# Make plugin statistics readable at a glance

In statistical plugin views, use plain-language metric labels, restrained numeric precision, and accessible explanations for compact visual encodings.

## Why

Compact statistics lose their value when the user must decode abbreviations or unexplained symbols before making a decision.

## Prefer

- Plain-language labels for per-game and per-90-minute statistics.
- One decimal place for ordinary comparison statistics.
- Tooltips on hover and keyboard focus explaining headers and unfamiliar indicators.

## Avoid

- Cryptic ratio abbreviations as the only explanation.
- Unnecessary decimal precision.
- Unexplained squares or numbered markers.

## Use when

- Designing compact statistical comparisons or unfamiliar indicators in a plugin.

## Do not use when

- Exact precision is essential to the task or the value is an identifier.

## Exceptions

- Retain greater precision when rounding would conceal a meaningful difference.

## Evidence

- Asked for understandable stat labels, one decimal place, accessible header tooltips, and explanations of unfamiliar waiver markers.

## Check

- Can the metric be understood without decoding an abbreviation?
- Are unfamiliar visual indicators explained on hover and keyboard focus?
- Does displayed precision serve the comparison?
