# Use explicit row actions inside navigation overflow

In bb's navigation overflow list, expose secondary row actions through an explicit action button rather than a right-click menu inside the popup.

## Why

An explicit row control makes secondary actions discoverable within an already-open navigation popup.

## Prefer

- Use a trailing action button for overflow row actions.

## Avoid

- Opening a second context menu by right-clicking a navigation overflow row.

## Use when

- Designing secondary actions on rows inside bb's navigation overflow popup.

## Do not use when

- Designing context menus on ordinary content or sidebar rows outside the overflow popup.

## Evidence

- Questioned right-click menus inside a context menu, then explicitly requested removing right-click and implementing the proposed alternative.

## Check

- Can a user find the overflow row actions through an explicit control?
- Does the overflow row avoid opening its own right-click action menu?
