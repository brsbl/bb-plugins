# Keep thread overflow actions consistent across header and sidebar

In bb, keep the thread header and sidebar overflow menus aligned so a thread action added to one is available in both.

## Why

People should find the same thread actions from either entry point.

## Prefer

- Make shared thread actions available from both overflow menus.

## Avoid

- Adding a shared thread action only to the header or only to the sidebar.

## Use when

- Adding or changing thread actions exposed through bb header and sidebar overflow menus.

## Do not use when

- Menus act on different objects or provide unrelated capabilities.

## Evidence

- The user asked to align header and sidebar overflow menus so additions to one appear in both.

## Check

- For the same thread and state, is the added action available in both overflow menus?
