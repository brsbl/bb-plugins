# Show only the active compact sidebar control

When a sidebar or tool panel is open in bb's compact layout, show only the expand/collapse control for that panel; hide the opposing sidebar trigger until it closes.

## Why

Competing sidebar icons make it unclear which panel a control operates and allow an unrelated sidebar to open from the active panel state.

## Prefer

- One visible expand/collapse control belonging to the currently open panel.

## Avoid

- Showing a left-sidebar trigger beside an open right panel.

## Use when

- Designing compact layouts where left and right sidebars share a center pane.

## Do not use when

- Designing desktop layouts with independently usable simultaneous panels.

## Evidence

- During mobile sidebar QA, the user asked to remove the opposing sidebar icon and allow only one sidebar expand/collapse control at a time.

## Check

- With either sidebar open, is its control the only visible sidebar expand/collapse control?
- Does closing the active panel restore the appropriate navigation controls?
