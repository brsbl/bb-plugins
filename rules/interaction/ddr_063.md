# Keep kanban section order consistent with the thread list

By default, bb views that present thread sections as kanban columns should follow the section order in the thread list.

## Why

Consistent section order preserves the user's existing spatial organization when switching views.

## Prefer

- Use the thread list's section order for kanban columns.

## Avoid

- An independently ordered kanban view of the same thread sections.

## Use when

- Presenting the same bb thread sections in a kanban view.

## Do not use when

- A view has a distinct ordering purpose explicitly requested by the user.

## Exceptions

- An explicit request for a separate board order overrides this default.

## Evidence

- The user objected to kanban columns differing from the thread list and chose matching the list over separate reordering.

## Check

- Does the kanban column sequence match the user's thread-list section sequence?
