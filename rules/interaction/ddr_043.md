# Keep reference images visible after theme generation

In image-based theme generation, retain visible source thumbnails after generation instead of replacing them with an image count.

## Why

The visual reference remains useful while judging and editing the generated theme.

## Prefer

- Persistent reference thumbnails that can be reopened for inspection.

## Avoid

- Collapsing reference images to a label such as an image count after generation.

## Use when

- Designing the reference-image portion of Theme Preview.

## Do not use when

- A separate compact resource summary outside the theme editing workflow.

## Evidence

- The user requested persistent lightbox-enabled reference thumbnails, then reiterated that generation must not replace them with a count.

## Check

- Are source thumbnails still visible after generation completes?
- Can the user inspect the reference while refining the result?
