# Keep disabled plugins in installed inventories

Disabling a plugin should leave it discoverable in both installed-plugin lists. Installed inventory membership follows installation state, not whether the plugin is currently enabled.

## Why

Disabled plugins remain installed; making them disappear suggests removal and makes re-enabling them harder.

## Prefer

- Keep disabled plugins visible in installed inventories across reloads.
- Show enabled state on the existing entry.

## Avoid

- Treating disabling as removal from the installed inventory.
- Moving a toggled plugin out of view through automatic enabled-first grouping.

## Use when

- Designing the default installed-plugin inventories and their enable controls.

## Do not use when

- Designing the Settings navigation list of enabled plugins with settings.

## Exceptions

- An explicitly selected enabled-only filter can intentionally exclude disabled entries.

## Evidence

- The user stated that disabled plugins are still installed and should stay listed permanently, then clarified that this applies to installed inventories rather than the Settings sidebar.

## Check

- Disable a plugin in each installed list and confirm it remains visible.
- Reload and confirm the disabled plugin remains in the installed inventory.
