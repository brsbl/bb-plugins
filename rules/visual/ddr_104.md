# Preserve sidebar label size during inline renaming

Keep the text size stable when a bb sidebar section label changes into an inline rename input.

## Why

Entering edit mode should preserve the label's visual scale instead of making it temporarily larger.

## Prefer

- Match the rename input's text size to the section label it replaces.

## Avoid

- A temporary increase in section label text size during renaming.

## Use when

- Switching bb sidebar section labels between display and inline editing states.

## Do not use when

- Designing a separate full-size editing screen.

## Evidence

- During sidebar rename testing, the user requested a fix for section text becoming temporarily larger in the input.

## Check

- Does entering and leaving section rename preserve the displayed text size?
