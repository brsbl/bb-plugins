# Keep thread project indicators stable without widening indentation

In bb thread lists, keep project indicators fixed on hover and integrate them into the existing tree-guide space without changing thread indentation or obscuring the hierarchy.

## Why

Stable markers and consistent indentation keep project identity and thread hierarchy easy to scan as row controls appear.

## Prefer

- Place the project indicator on the left in the existing tree-guide space.
- Preserve thread indentation and readable guide lines when an indicator is present.

## Avoid

- Project indicators that shift when a row is hovered.
- Adding indentation solely to accommodate the project indicator.
- Indicator placement that unintentionally cuts off hierarchy guides.

## Use when

- Positioning project indicators in hierarchical bb thread rows.

## Do not use when

- Designing unrelated icons or lists without hierarchy guides.

## Evidence

- Requested a left-side project indicator that stays still on hover, then suggested placing it in the guide line to preserve indentation and questioned clipped guides.

## Check

- Does the indicator stay in the same position when the row is hovered?
- Do rows retain their existing indentation and readable hierarchy guides with the indicator present?
