# Truncate mobile composer control labels

In bb's mobile composer, truncate long selector labels rather than wrapping the controls; apply the same behavior with and without a selected project.

## Why

Long selections should fit the compact composer controls without overlapping adjacent controls or changing their row layout.

## Prefer

- Truncated labels in constrained selector controls.
- Consistent overflow behavior in project-selected and no-project states.

## Avoid

- Wrapping mobile composer controls to accommodate long labels.
- Labels overlapping neighboring controls.

## Use when

- Laying out selected dropdown labels under the bb prompt box on mobile.

## Do not use when

- Designing dropdown menu contents, desktop layouts, or prose overflow.

## Evidence

- The user rejected wrapping mobile composer controls and requested truncation matching the existing project-selected behavior.

## Check

- Do long selected labels truncate without overlapping neighboring controls?
- Does truncation work both with and without a selected project?
