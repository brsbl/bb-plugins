# Fix sidebar action spacing without enlarging approved icons

When bb's mobile sidebar action buttons feel too far apart, adjust their spacing while preserving the icon sizes the user already likes.

## Why

Larger glyphs change visual weight without resolving the underlying spacing concern.

## Prefer

- Treat glyph size and spacing as separate design decisions.
- Preserve the existing glyph size when tightening the action pair.

## Avoid

- Enlarging icons as a substitute for changing action spacing.
- Overlapping adjacent touch targets to conceal excess spacing.

## Use when

- Refining spacing between bb's mobile sidebar action buttons.

## Do not use when

- The reported problem is icon legibility or icon size itself.

## Exceptions

- Accessibility or a separately approved icon redesign can justify changing glyph size.

## Evidence

- Rejected enlarged sidebar icons because spacing had not changed, said the original icon sizes were liked, and questioned overlapping touch targets.

## Check

- Did the gap change without enlarging the glyphs?
- Do adjacent actions retain distinct, usable touch regions?
