# Group install counts with the install action

On plugin marketplace cards, present install count as quiet metadata beside the install control and retain it after installation.

## Why

The count explains the install action and should read as part of that control rather than a competing card element.

## Prefer

- Keep the count adjacent to the install control.
- Show the count in both uninstalled and installed states.
- Use a plain count without a duplicate install glyph.

## Avoid

- Giving the count its own repeated install icon.
- Hiding the count after installation.
- Separating install metadata from its action.

## Use when

- Designing plugin marketplace cards that display install counts.

## Do not use when

- Presenting installation analytics in a reporting surface.

## Evidence

- During marketplace card refinement, explicitly called the count metadata for the install button, removed its duplicate glyph, and kept it visible after installation.

## Check

- Does the count read as metadata for the adjacent install control?
- Is the count still visible when installed?
- Is there only one install glyph in the group?
