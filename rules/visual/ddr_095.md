# Follow system appearance through a page's own theme

When adapting pages in BB's browser to the system appearance, prefer the page's existing light and dark themes over injected replacement styling.

## Why

Following system appearance should preserve the website's intended theme design.

## Prefer

- Activating the page's own theme in response to the selected system appearance behavior.

## Avoid

- Treating injected dark CSS as equivalent to using a page's existing dark theme.

## Use when

- Designing automatic system-theme matching for pages viewed in BB's browser.

## Do not use when

- Designing BB's own application theme.
- A page has no existing theme to activate.

## Exceptions

- Custom recoloring may be appropriate if explicitly requested by the user.

## Evidence

- When discussing browser pages following the system theme, the user explicitly rejected injected styling and asked to use each page's existing dark mode.

## Check

- Does the page render its own theme rather than a replacement stylesheet?
- Is the system-theme behavior clearly distinguished from custom recoloring?
