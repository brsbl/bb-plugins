# Make split send controls feel like one control

Keep a composer split send button visually unified: use a subtle inset divider and small chevron, and update both segments together when the shared control state changes.

## Why

A dominant divider and sequential segment updates make one send control feel like unrelated buttons.

## Prefer

- A short inset separator and small dropdown chevron.
- Simultaneous visual transitions across the send and menu segments.

## Avoid

- A full-height divider dominating the send control.
- One segment visibly updating before the other.

## Use when

- Designing or changing the split send control in the bb composer.

## Do not use when

- Designing independent adjacent actions that have different states.

## Evidence

- During composer refinement, the user requested a subtler divider and smaller chevron, then twice objected to send-button segments updating separately.

## Check

- Is the separator inset rather than full height?
- Do both segments visibly update together as the composer state changes?
