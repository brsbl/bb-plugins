# Keep seeded handoff prompts editable before submission

When a handoff adds a source reference or suggested wording to a prompt, insert it into the editable draft before submission so the user can customize the complete message; submit the message they reviewed.

## Why

Adding wording only at submission takes control of the outgoing message away from the user.

## Prefer

- Seed suggested handoff text in the visible, editable composer when the user chooses the destination.

## Avoid

- Silently prepending handoff wording when the user submits.

## Use when

- A handoff flow adds text or references to the user's outgoing prompt.

## Do not use when

- Managing internal context that is not represented as user-authored prompt text.

## Evidence

- Rejected a source reference added at submission and asked to insert it on model selection so the full message could be customized.

## Check

- Can the user edit or remove every seeded part before submitting?
- Does the submitted message match the reviewed draft?
