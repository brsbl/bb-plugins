# Keep agent references compact and composable

Copy-for-agent actions should produce distinct composable pills with minimal guidance pointers and a short natural-language frame; avoid repeating context already carried by the reference.

## Why

People should be able to combine capabilities into their own request without a documentation dump.

## Prefer

- Separate pills for separate capabilities.
- Minimal guidance pointers and brief surrounding framing.

## Avoid

- Tutorial excerpts or verbose plain-text reference payloads.
- Instructions duplicating the attached context.

## Use when

- Designing or revising the bb Plugin Guide and its capability examples.

## Do not use when

- Unrelated product layouts or technical API reference documentation.

## Evidence

- Requested distinct composable pills with minimal pointers instead of documentation excerpts.
- Asked for framing copy around the pill, then rejected redundant wording about using the guide.

## Check

- Do multiple pasted capabilities remain distinct and composable?
- Does framing avoid repeating the pill context?
