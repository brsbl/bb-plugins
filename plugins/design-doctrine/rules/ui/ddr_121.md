# Never show raw entity IDs; render resolved mention pills consistently

Wherever a stored string contains an entity reference (e.g. a thread mention ID), render it as the resolved mention pill with the human-readable name on every surface, and make search and filtering match the visible name, not the hidden ID. Inside surfaces that are themselves interactive rows (menus, pickers, lists), the pill is display-only, not separately clickable.

## Why

Raw IDs are meaningless to users and break the illusion that the pill is the name; a name visible in one place but raw in another, or unfindable by what is shown, feels broken.

## Prefer

- One shared title/mention renderer used on every surface
- Search that matches the displayed resolved name as well as stored text
- Non-interactive pills when nested inside a clickable row or menu item
- Tooltips and plain-text contexts (tab titles, drag labels) using the resolved name

## Avoid

- Leaving raw @thread:thr_… text on any surface
- Pills that are clickable inside rows that already have their own click action
- Search that only matches hidden IDs

## Use when

- Rendering titles or text that may embed entity mentions

## Do not use when

- Debug or developer views where the raw ID is the point

## Evidence

- User asked that thread IDs resolve to mention pills across all surfaces, non-clickable in menus, then insisted remaining raw-title surfaces and visible-name search all be fixed.

## Check

- Grep surfaces that render titles for raw mention syntax
- Search by a pill's visible name finds the item
- Pill inside a menu row does not intercept the row's click
