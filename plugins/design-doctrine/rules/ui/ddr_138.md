# Truncate long pin preview addresses

Truncate long addresses in Pinned Links preview headers with an ellipsis; do not turn the address into a horizontal scroller.

## Why

Keeps the preview header compact and consistent without a separate scrolling interaction.

## Prefer

- Ellipsis truncation for long preview addresses

## Avoid

- Scrolling long addresses horizontally to reveal them

## Use when

- Displaying a long URL or file path in a Pinned Links preview header

## Evidence

- The user requested ellipsis truncation instead of scrolling for long addresses in Pinned Links previews.

## Check

- Long addresses remain on one line with ellipsis truncation at rest, on hover, and on keyboard focus.
