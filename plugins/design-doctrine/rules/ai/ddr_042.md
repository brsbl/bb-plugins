# Keep agent workflow instructions synchronized with user settings

When users configure workflow sections and their rules, the plugin should automatically update the corresponding agent-skill content so agents act on the saved preferences.

## Why

Customizing the visible workflow must also change the instructions that guide agents through it.

## Prefer

- User-editable section titles and routing descriptions.
- Automatically inject saved preferences into a predefined skill slot.

## Avoid

- A separate manually maintained instruction copy.
- Settings that change the UI while agents keep using stale workflow rules.

## Use when

- A bb plugin exposes user-configurable workflow rules consumed by agents.

## Do not use when

- Settings are purely visual and do not affect agent behavior.

## Evidence

- Requested configurable section rules that update the supplied skill, then clarified that saved preferences must be injected into a predefined slot in real time.

## Check

- After a user saves workflow rules, do agent instructions reflect those rules automatically?
- Is there a single user-facing source for those preferences?
