# Keep interface copy concise without losing meaning

Use the fewest words that preserve understanding and user value; remove repetition and implementation detail so actions remain the focus.

## Why

Reduce distraction while keeping users informed.

## Prefer

- Concise task-focused wording
- Details needed to understand actions and outcomes

## Avoid

- Repetitive explanations
- Shortening that obscures meaning or value

## Use when

- Writing or refining interface copy

## Evidence

- The user requested concise onboarding copy that retains understanding and value to improve focus.

## Check

- Does each phrase help the person understand the value or take the next action?
