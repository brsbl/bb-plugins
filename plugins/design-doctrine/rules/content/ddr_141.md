# Keep docs pages and the docs sidebar visually light

Docs pages and the docs sidebar should read at a glance: short sidebar labels, answers in steps, tables and images rather than paragraphs, and as little prose as the answer needs.

## Why

Text-heavy docs are slow to scan and hide the answer.

## Prefer

- Short sidebar labels
- Numbered steps, tables and screenshots
- Paragraphs of three lines or fewer

## Avoid

- Intro paragraphs that repeat the page description
- Long prose explanations
- Long page titles in navigation

## Use when

- Writing or reviewing bb docs pages or docs navigation

## Do not use when

- Generated reference tables that must list everything

## Evidence

- The user reviewed a docs preview and said the pages, and then the sidebar, were too text heavy.

## Check

- Does the page answer in the first two lines?
- Is any paragraph longer than three lines?
- Do sidebar labels fit on one line?
