# Product docs: comprehensive but succinct, useful, and easy to navigate

bb's product docs must cover the product comprehensively while staying succinct and useful, rank in search, and make the site easy to navigate.

## Why

The first docs round was judged poor; docs must both win search traffic and genuinely help readers find what they need.

## Prefer

- Cover every user-facing feature
- Short pages that answer the task directly
- Clear navigation across the site
- Pages structured to rank for real searches

## Avoid

- Thin or padded pages
- Gaps in feature coverage
- Docs that are hard to navigate

## Use when

- Planning, writing or reviewing bb product docs on getbb.app

## Evidence

- The user said the first docs round was bad and set the bar: comprehensive, succinct, useful, ranked, easy to navigate.

## Check

- Does every user-facing feature have a findable page?
- Is each page succinct and directly useful?
- Can a reader navigate to related pages easily?
- Is each page built to rank for a real search?
