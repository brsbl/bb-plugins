# Keep mobile analytics controls with their title

In bb analytics views on mobile, align view controls with the title instead of presenting them as a floating control cluster.

## Why

Controls should read as part of the view they operate on.

## Prefer

- Title-aligned controls within the mobile view header.

## Avoid

- Floating control clusters detached from the view title.

## Use when

- Arranging mobile headers for bb PostHog analytics views.

## Do not use when

- Designing unrelated floating actions, overlays, or desktop toolbars.

## Evidence

- The user rejected floating mobile analytics controls, requested alignment with the title, and extended that feedback to traffic sources.

## Check

- Are mobile view controls visibly grouped and aligned with the title?
