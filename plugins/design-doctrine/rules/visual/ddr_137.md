# Keep section hover-card text sizes consistent

Use a consistent text size across section hover-card metadata, attention indicators, and empty, loading, and unavailable states.

## Why

Keep the section card's hierarchy coherent across content and fallback states.

## Prefer

- Match these text sizes to the other section-card text and use weight, icons, and color for hierarchy.

## Avoid

- Oversized attention rows or fallback messages relative to the rest of the section card.

## Use when

- Styling the section hover card's attention row or empty, loading, and unavailable states.

## Evidence

- The user requested matching section-card text sizes across attention and fallback states.

## Check

- Do attention, empty, loading, and unavailable text match the size of the other section-card text?
