# Align sidebar thread status in one column across nesting levels

In bb sidebar thread lists, keep status indicators in one shared column across nesting depths rather than indenting them with each thread title.

## Why

A shared status column makes thread states easier to scan across the hierarchy.

## Prefer

- Keep the status column independent of title indentation.

## Avoid

- Treating alignment only among rows at the same depth as a single status column.

## Use when

- Designing status placement in hierarchical bb sidebar thread lists.

## Do not use when

- Laying out unrelated icons or status indicators outside sidebar thread lists.

## Evidence

- Asked whether status occupied one column, then objected that the variant with indented status was not aligned and requested the fixed-column variant in fuller sidebar context.

## Check

- Do status indicators share the same horizontal center across parent and nested thread rows?
