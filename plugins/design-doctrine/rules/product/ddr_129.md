# Use arrows and fades for reasoning overflow

Use arrows and fading edges instead of a visible scrollbar for the model picker's horizontally scrolling reasoning row.

## Why

Make additional options discoverable without a visible scrollbar.

## Prefer

- Scroll arrows and fading overflow edges

## Avoid

- Visible horizontal scrollbar

## Use when

- Designing horizontal scrolling in the model reasoning row

## Evidence

- User requested hidden scrollbars with arrows and fading edges for horizontal navigation in the model reasoning row.

## Check

- Overflowing edges fade and have arrows for horizontal navigation
