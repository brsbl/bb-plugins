# Collection toolbar stays on one line, matches grid width

Collection controls (search, filters, sort, primary action) form one shared toolbar exactly as wide as the content grid at every size; labeled controls get space first, search fills the remainder, and at narrow widths controls collapse into a combined filter-and-sort dropdown rather than wrapping.

## Why

Wrapping toolbars, oversized search bars, and artificial gaps look broken and waste space that labels could use.

## Prefer

- Continuous row with consistent small gaps
- Labels in buttons when width allows
- A labeled combined Filter & sort dropdown at narrow widths
- Expand search on focus on mobile if too narrow

## Avoid

- Toolbars wrapping to two lines
- A wide, mostly empty search bar while controls lose labels
- Spacer gaps between search and controls
- Calling the combined control an overflow (…) menu

## Use when

- Building a list/grid page with search plus filter/sort controls

## Exceptions

- A mobile primary create action may keep its label for clarity

## Evidence

- User repeatedly corrected toolbar wrapping, width, gaps, and narrow-width collapsing on one feature.

## Check

- Toolbar edges align with grid edges at 320–1440px
- No wrapping at any width
