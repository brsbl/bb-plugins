# Compact mobile collection pages

On mobile, shorten curated shelves to about two items with See all, hide non-essential hero and description text so shelf title and See all share one line, and open See all as its own route for easy Back navigation.

## Why

Long stacked shelves push other content below the fold on small screens.

## Prefer

- Two-card mobile shelves
- Dedicated shelf route for See all
- Underlined See all link

## Avoid

- Full six-card shelves stacked on mobile
- Shelf descriptions wrapping the See all action

## Use when

- Rendering grouped shelves on narrow viewports

## Do not use when

- Management lists where users need every item and its controls visible

## Evidence

- User iteratively shortened mobile shelves, hid hero and descriptions, and asked for a See all route.

## Check

- Two shelves are reachable within about one mobile scroll
