# Promo device shots show the product working, with minimal copy

In promotional device mockups of bb, show real product surfaces actively doing work (a running plugin, live threads, inline data viz) rather than catalog or marketplace pages, and keep on-image copy to a single wordmark with no taglines; render the device flat-on so screen content stays crisp.

## Why

The impressive part of a promo shot is the live product; taglines, duplicate logos, and browse-only pages dilute it, and angled 3D renders blur the UI being shown.

## Prefer

- an installed plugin actually running with live state
- threads with rich output such as inline charts
- one bb wordmark as the only copy
- flat, sharp device framing

## Avoid

- marketplace or catalog pages as the hero
- taglines and multiple logo instances
- angled/perspective device renders that soften screen text
- redundant UI labels and controls that add noise in the shot

## Use when

- creating promotional screenshots or device mockups of bb for social posts

## Do not use when

- the user asks for annotated, captioned, or explanatory marketing graphics

## Evidence

- User removed taglines, asked for a single wordmark, replaced a marketplace page with a running plugin, added inline data viz, and rejected an angled render for blur during one promo mockup session.

## Check

- Is the hero surface showing live work rather than a browse page?
- Is the only copy a single wordmark?
- Is screen text sharp at full resolution?
