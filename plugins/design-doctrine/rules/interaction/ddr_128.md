# Place submenu entries after plain actions within each menu group

In bb menus, within each divider-separated group, list plain actions first and items that open a submenu last.

## Why

Submenu entries feel heavier than direct actions; putting them last gives each group a predictable order.

## Prefer

- List Rename before Move to section in the same group.
- List Mark read and Pin before Notifications in the same group when Notifications opens a submenu.

## Avoid

- Placing a submenu entry above plain actions within the same divider group.

## Use when

- Ordering actions within one divider-separated group in a bb menu that contains both plain actions and submenu entries.

## Do not use when

- The group has no submenu entries.
- A platform convention or explicit task requirement fixes the action order.

## Evidence

- Asked for Rename before Move to section because submenu entries feel heavier and belong at the bottom of the group.

## Check

- Within each divider group, do all plain actions precede every submenu entry?
