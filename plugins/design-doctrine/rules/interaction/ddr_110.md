# Show the selection path through hidden sidebar sections

When the open thread belongs to a hidden sidebar section, mark More, the containing section, and the thread as selected at their respective levels so users can retrace the path to it.

## Why

A hidden section otherwise conceals where the current thread belongs. Selection along the path makes it findable again.

## Prefer

- Carry the active-thread indication through More and its containing section.

## Avoid

- Showing selection only on the thread while its containing navigation levels give no location cue.

## Use when

- The active thread is inside a sidebar section accessed through More.

## Do not use when

- The active thread is already in a visible sidebar section.

## Evidence

- The user requested selection on More, the hidden section, and the active thread to give users a breadcrumb for finding the thread again.

## Check

- Open a thread in a hidden section and confirm More indicates its active descendant.
- Open More and the containing section and confirm the selection path leads to the active thread.
