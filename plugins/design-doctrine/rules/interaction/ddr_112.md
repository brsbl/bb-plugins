# Use arrow glyphs in palette shortcut hints

In bb command-palette shortcut hints, display directional arrow keys as ←, →, ↑, and ↓ instead of raw ArrowLeft, ArrowRight, ArrowUp, and ArrowDown names.

## Why

Arrow glyphs present directional keys in a compact, recognizable form.

## Prefer

- Show arrow glyphs for directional keys in visible palette shortcut hints.

## Avoid

- Showing raw Arrow[Direction] key names in palette shortcut hints.

## Use when

- Designing or revising visible directional-key shortcut hints in the bb command palette.

## Do not use when

- Documenting literal key identifiers or representing shortcut data.

## Evidence

- Asked to replace Arrow[Direction] shortcut labels with arrow keys in the palette.

## Check

- Do directional-key shortcut hints show arrow glyphs instead of raw key names?
