# Refresh on load instead of manual check/refresh buttons

When data can be checked cheaply, refresh it automatically in the background on page load instead of offering a manual Check, Refresh, or Reload button.

## Why

Manual refresh controls add chrome and make users do work the app can do itself.

## Prefer

- Background check on page load, then update the view in place

## Avoid

- Check-for-updates buttons
- Refresh or reload icons in collection toolbars

## Use when

- Status or update information can be fetched without user cost

## Do not use when

- The check is expensive, rate-limited, or has side effects the user must approve

## Evidence

- User asked three times in one project to drop check/refresh/reload buttons and refresh on page load.

## Check

- No manual refresh control exists for data that loads automatically
