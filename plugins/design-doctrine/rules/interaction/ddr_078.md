# Make mobile image previews easy to dismiss

Use a chromeless lightbox for mobile image previews, with tap-to-dismiss and a visible X that clearly communicates how to close it.

## Why

Image viewing should be easy to leave; a drawer treatment can make dismissal difficult to discover or perform.

## Prefer

- A minimal image overlay with tap-to-dismiss.
- A visible close affordance alongside tap dismissal.

## Avoid

- Mobile image drawers with difficult dismissal.
- Relying only on an undisclosed dismissal gesture.

## Use when

- Designing or revising bb mobile image previews.

## Do not use when

- Designing drawers for editing or other tasks beyond image viewing.

## Evidence

- In mobile lightbox feedback, the user described drawer dismissal as difficult and requested a chromeless preview with tap dismissal and a visible X.

## Check

- Can the user dismiss the mobile image preview by tapping?
- Is a visible X available as an explicit close affordance?
