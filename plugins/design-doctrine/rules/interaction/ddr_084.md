# Keep mobile New Thread suggestions above the prompt

On the mobile New Thread page, default to opening typeahead above the prompt so the on-screen keyboard does not obscure suggestions.

## Why

Suggestions need to remain visible and selectable while the user types with the on-screen keyboard open.

## Prefer

- Place the mobile New Thread typeahead above its prompt.

## Avoid

- Opening suggestions below the prompt where the on-screen keyboard obscures them.

## Use when

- Designing typeahead placement on the mobile New Thread page.

## Do not use when

- Choosing desktop menu placement or positioning unrelated popovers.

## Evidence

- The user reported keyboard overlap on mobile New Thread and explicitly requested typeahead above the prompt.

## Check

- With the mobile keyboard open, are suggestions visible and selectable above the prompt?
