# Require full hex codes for inline color swatches

In mixed prose, activate automatic hex color swatches only for full color codes so short hash references in PR titles do not receive color decoration.

## Why

Short hash references can resemble abbreviated colors and create unwanted swatches in ordinary text.

## Prefer

- Full hex color codes as the trigger for automatic swatches in mixed prose.

## Avoid

- Decorating short hash references as colors.

## Use when

- Detecting hex colors automatically in text that can also contain PR references.

## Do not use when

- Designing a dedicated color input where the user explicitly supplies a color.

## Evidence

- Asked to restrict swatches to full color codes because short matches incorrectly activated in PR titles.

## Check

- Do short PR references remain free of swatches?
- Do full hex color codes still activate swatches?
