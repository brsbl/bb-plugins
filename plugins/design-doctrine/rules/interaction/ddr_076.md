# Keep collapsed sidebar rows focused on status

In bb's mobile sidebar, hide row action buttons while a row is collapsed. Keep the missing-folder warning visible, and hide the overflow menu on collapsed project rows with that warning, including on desktop.

## Why

Collapsing a sidebar row should reduce action clutter while leaving problems visible.

## Prefer

- Reveal mobile row actions on expansion.
- Retain missing-folder warnings when the row is collapsed.
- Hide the overflow menu on collapsed project rows with a missing-folder warning.

## Avoid

- Leaving mobile row action buttons visible after collapse.
- Hiding the missing-folder warning along with ordinary actions.
- Showing an overflow menu on a collapsed project warning row.

## Use when

- Designing collapse behavior for bb sidebar rows and project warning states.

## Do not use when

- Designing unrelated lists or toolbars.
- Changing desktop actions outside the project warning state.

## Evidence

- In one sidebar refinement episode, the user requested hidden collapsed mobile actions, asked to fix the hidden warning, and removed the collapsed warning-row overflow menu.

## Check

- Does collapsing a mobile sidebar row hide its action buttons?
- Does a collapsed project still show its missing-folder warning?
- Is the overflow menu hidden on a collapsed project warning row on mobile and desktop?
