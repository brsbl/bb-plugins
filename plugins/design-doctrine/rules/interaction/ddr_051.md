# Keep child failures visible in collapsed thread hierarchies

When a collapsed bb thread hierarchy hides an errored direct child, surface the failure on the visible parent using the existing error treatment; expanding should expose the child's original error.

## Why

Collapsing a hierarchy should not hide a child failure that needs attention.

## Prefer

- Show the existing error indicator on the visible parent when an errored direct child is hidden.
- Reveal the original child error when the hierarchy is expanded.

## Avoid

- Making a hidden child failure invisible until the user expands the hierarchy.
- Showing a child-error indication for healthy children.

## Use when

- Designing collapsed and expanded states of bb thread hierarchies containing direct child errors.

## Do not use when

- Defining error propagation through arbitrary descendant depths or across unrelated threads.

## Evidence

- Asked for a parent to surface a collapsed direct child's error using existing error treatment, with expansion revealing the original error.

## Check

- Is a hidden direct child's error visible on its parent?
- Does expansion reveal the child's original error?
- Do healthy children retain their normal treatment?
