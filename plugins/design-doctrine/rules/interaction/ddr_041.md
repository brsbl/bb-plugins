# Choose section icons visually and in their displayed position

Section icon controls should show the actual icons and sit to the left of the section title, matching the sidebar presentation.

## Why

Users select a visual symbol more directly when the control previews the symbol in its intended relationship to the label.

## Prefer

- A visual icon picker.
- An icon control before the section title.

## Avoid

- Choosing icons solely by implementation names.
- Placing the icon control away from the position where the icon appears.

## Use when

- Editing icons for bb sidebar sections.

## Do not use when

- The setting is not choosing a visual symbol or the destination uses a different layout.

## Evidence

- Requested a visual icon picker placed left of the section title because that is where the icon appears.

## Check

- Can users recognize the actual symbol before choosing it?
- Does the editor reflect the icon-label order in the sidebar?
