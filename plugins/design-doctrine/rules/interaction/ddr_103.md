# Keep sidebar inline rename free of Save and Cancel icons

In bb sidebar inline rename fields, prefer the existing keyboard and blur interactions without additional checkmark Save or X Cancel buttons.

## Why

Extra action icons add controls to a compact naming interaction that already has save and cancel gestures.

## Prefer

- Use Enter or clicking away to save and Escape to cancel in this inline rename interaction.

## Avoid

- Adding checkmark and X buttons to sidebar rename fields by default.

## Use when

- Designing or revising bb sidebar inline rename fields with existing keyboard and blur behavior.

## Do not use when

- Designing multi-field forms or editors whose save and cancel behavior differs.

## Exceptions

- Explicit controls may be needed where the available input methods do not provide usable save and cancel gestures.

## Evidence

- During sidebar rename review, the user questioned the checkmark and X icons and explicitly requested their removal.

## Check

- Does the sidebar rename field avoid extra Save and Cancel icons while retaining usable save and cancel interactions?
