Keep the files you return to beside the conversation they belong to.

Pin a file from any enrolled machine using the thread's **Pin a file** action
or `bb file-pins pin`. Filenames remain visible above the composer and open in
bb's file viewer, including installed file-opener plugins such as Moss viewer.

Pins persist per thread across clients and restarts. Unpinning removes only the
shortcut. Files stay on their original machine; no file contents are copied.
