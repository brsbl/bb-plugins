# SceneSeed Three.js interpretation examples

Use these as composition precedents, not templates to copy. A good result
keeps the prompt's central relationship legible while taking advantage of
Three.js geometry, hierarchy, and local helper functions.

## Literal

### Tiny lighthouse

- Build a tapered tower, balcony rail, glass lantern room, roof, narrow window
  insets, and a restrained beam.
- A lathed tower profile or repeated window helper produces a more convincing
  silhouette than stacked generic blocks.

### Cactus in a teacup

- Use a cup profile with a curved handle and a branching capsule cactus.
- Let the glossy pale cup and matte dark plant carry the value contrast.

## Metaphorical

### A rainy thought in a jar

- Build a transparent vessel around an irregular cloud assembled from several
  overlapping lobes, with fine line or point rain contained inside it.
- Keep the containment relationship readable from the chosen camera.

### Hope growing through concrete

- Separate two heavy slab fragments around a curved stem with procedural
  leaves. The split and negative space matter more than surface decoration.

## Spatial

### A sphere balanced between two towers

- Make the contact points unambiguous. Use a front or three-quarter camera and
  small architectural variation without obscuring the balance.

### A key floating inside a transparent cube

- Construct a recognizable key from a ring, shaft, and teeth, rotate it within
  a physical glass box, and preserve visible clearance on every side.

## Abstract

### Two ideas almost meeting

- Use two distinct procedural clusters leaning toward a charged central gap.
  Preserve the negative space instead of filling it with an explanation.

### Organized chaos

- Repeat a coherent outer frame around varied internal geometry generated by
  a short deterministic loop. Keep the rhythm intentional.

## Complete Three.js source

The `source` value is this JavaScript function body as a string. `THREE` is
already in scope.

```js
const root = new THREE.Group();

const dark = new THREE.MeshStandardMaterial({
  color: 0x222222,
  roughness: 0.78,
  metalness: 0.08,
});
const pale = new THREE.MeshPhysicalMaterial({
  color: 0xeeeeee,
  roughness: 0.2,
  transmission: 0.35,
  transparent: true,
  opacity: 0.82,
});

const profile = [
  new THREE.Vector2(0.72, 0),
  new THREE.Vector2(0.66, 2.8),
  new THREE.Vector2(0.52, 4.6),
];
const tower = new THREE.Mesh(new THREE.LatheGeometry(profile, 32), dark);
root.add(tower);

const lantern = new THREE.Mesh(
  new THREE.CylinderGeometry(0.48, 0.48, 0.85, 24),
  pale,
);
lantern.position.y = 5.05;
root.add(lantern);

const balcony = new THREE.Mesh(
  new THREE.TorusGeometry(0.7, 0.055, 10, 36),
  dark,
);
balcony.rotation.x = Math.PI / 2;
balcony.position.y = 4.55;
root.add(balcony);

const roof = new THREE.Mesh(new THREE.ConeGeometry(0.72, 0.8, 32), dark);
roof.position.y = 5.86;
root.add(roof);

const lanternLight = new THREE.PointLight(0xffffff, 1.2, 7, 2);
lanternLight.position.set(0, 5.05, 0);
root.add(lanternLight);

return {
  root,
  name: "Tiny lighthouse",
  altText: "A tapered dark lighthouse with a pale lantern room, balcony ring, and pointed roof.",
  camera: "three-quarter",
  movement: "still",
  shadow: "crisp",
};
```
