# Digests

Private briefings that arrive as ordinary bb threads. Each issue opens with a
clear headline, numbered priorities and review buttons. Routine detail stays
collapsed. Move or archive issues yourself when done.

Add a digest under a signed-in site in Settings: give it a name, describe what
it should tell you, and choose a schedule. Existing starter definitions for
Unread email, Money and Reading stay disabled until migration is confirmed.
X scorecards can be published by another thread with `bb digest publish`.

Uses existing bb Browser sign-ins; import opens bb’s own Browser settings.
Failures show Retry or Reconnect. Reading remembers summarized newsletters
without marking Gmail read. Collection is read-only; only an approved Inline
Action Card click authorizes an external write.
