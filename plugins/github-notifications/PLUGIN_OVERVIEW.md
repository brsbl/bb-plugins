## Your incoming GitHub activity

Open GitHub Activity from the sidebar to see comments and mentions on pull requests and issues you authored. The feed uses the account signed in through the GitHub CLI.

- Search by title, repository, or person.
- Filter pull requests and issues, comments and mentions, or open and resolved activity.
- Sort the table and follow each resource's GitHub link.
- Mark activity resolved in bb without marking the GitHub notification read. New activity can return an item to the open list.

## Requirements

Install the GitHub CLI on the machine running the bb server and sign in with `gh auth login`. If the CLI is missing or signed out, the panel shows setup guidance and a retry action. Credentials stay with the GitHub CLI; the plugin does not ask you to paste a token.
