# Canvas Desktop

A spatial bb workspace: Desktop's folders and windows on an infinite, zoomable canvas, without the Windows XP skin. Open `/plugins/desktop-canvas-prototype/desktop` from the sidebar.

## Use

- **Folders mirror the sidebar.** The canvas shows the sidebar's own organization (custom sections, projects or machines), in the sidebar's order, with Pinned first, environment folders when the sidebar groups by environment, and the groups you hid in the sidebar inside a More folder. Organize, Sort by, Filter and Visible groups in the canvas's right-click menu and the launcher's View options are the sidebar's own settings: changing them here changes the sidebar, and changes made in the sidebar show up here. Desktop folders, which only the canvas has, sit after the sidebar's groups. Dropping a thread on a section moves it into that bb section, dropping it on Threads takes it out of its section, and dropping it on a desktop folder files it there. Archived threads live in the Recycle Bin: drag a thread onto it to archive, right-click inside it to restore.
- **Arrange the canvas like Desktop.** Drag across empty canvas to select several folders, or ⌘/Ctrl/Shift-click to add and remove. Drag any selected folder to move them together, arrow keys nudge them (Shift moves a full slot), Delete removes selected desktop folders and sections after a confirmation, and ⌘/Ctrl-A selects everything. Drop folders on the Recycle Bin to delete them. Right-click the canvas for New folder (where you clicked), Tile windows, Cascade windows, Show desktop, Next and Previous window, Zoom to 100%, Fit all, the sidebar's view options and Arrange like sidebar. Icon positions are saved by the plugin, so they follow you to other browsers.
- **A canvas with places.** A folder opens beside its icon, and a thread opens beside the folder window it came from (or its folder's icon), in the nearest free space that leaves every folder visible. Opening or switching to a window flies the camera there: short hops ease straight over, longer trips pull back to show the canvas on the way. Zoom out past 70% and each window fades to its title and what it's doing (a thread's agent working or waiting, a folder's thread count, a page's site), sized to stay readable at any zoom; drag anywhere on a zoomed-out window to move it, and double-click to fly in to 100%.
- **Move around.** Scroll or two-finger swipe pans; hold Space and drag, or drag with the middle button, to pan with a mouse. Pinch, or ⌘/Ctrl-scroll, zooms around the pointer, including over windows; ordinary scrolling inside a window stays in the window. With the canvas focused, arrow keys pan, + and − zoom, 0 returns to 100% and ⇧1 fits everything. The canvas has a quiet grid and a muted bb mark.
- **Windows.** Folders open as Finder windows with Back and Forward, search, icon and list views, subfolders and a New thread button; threads open as bb conversations. Windows are translucent glass that follows bb's theme and Ambient. Drag a title bar to move a window, drag any edge or corner to resize it, double-click the title bar to maximize it, and drag a maximized window to pull it back onto the canvas. Drag a title to the left or right edge, or use its Position button, to dock it flush beside bb's panel; each side holds one window, and docking another returns the previous one to the canvas. Docked windows stay put while the canvas pans and zooms; drag the title away or choose Undock to float it again. Focus a title and use arrow keys to move it without a pointer. Opening a window brings it into view at 100%. Each window has a dock button: click to bring it forward, click again to minimize; right-click for Minimize, Maximize, Dock and Close. Buttons that don't fit collapse into a +N button. Thread and mention links inside a window open that thread as another window.
- **Threads, as Desktop has them.** A thread opens as a window with bb's own chat and an editable permission picker; threads carry no icon, as in the sidebar, unless the sidebar shows provider icons. A strip under the title says what the agent is doing (working, waiting for your reply, idle for how long) and holds the thread's tools. **Related threads** docks a list of the threads in the same project, or the same environment, on the left: grouped by desktop folder, waiting and working threads first, idle ones dimmed with how long they've been idle, archived ones folded away. **Info** docks the thread's status, agent, branch, environment, machine, pull request, section and folders on the right, with Open in bb, Mark read, Pin and Archive. Both stay attached: they move, resize to the thread's height, come forward, minimize and close with it. **Terminal** opens a real bb terminal in the thread's environment; closing the window ends it. **Browser** opens a page for the thread in bb's in-app browser, and in the bb desktop app a web link clicked in a thread's chat, Info or Related threads opens in that thread's browser window beside it; another link from the same thread reuses the window. Right-click a link to open it in your own browser instead. A native page shows only while its window is at 100%, fully on the canvas and uncovered; otherwise a quiet placeholder names the page. On the web, where bb has no browser to draw a page into, links open in a new tab and the canvas says so once. With the Side chat plugin installed, a message's actions include Reply in side chat. When a thread starts waiting for you, a notice above the dock names it; click to open its window.
- **Thread actions.** Right-click a thread, or use a thread window's … button, for Open in bb, Open in split, Move to, Remove from folder, Copy thread link, Mark as read or unread, Pin, Rename, Archive or Restore, and Delete. Right-click a link in a chat to open or copy it.
- **Composer.** The dock's Launcher offers Composer, My Threads, New folder and View options. Composer opens bb's native prompt just above the dock, with its grip and × in one rounded frame. Drag the grip to move it, or focus the grip and use arrow keys; × minimizes it, and the draft stays. A folder's New thread files the thread into that section, project or desktop folder.

The first version kept desktop folders in this browser only; they move to the plugin's storage the first time this version loads. Window layout, docking and the camera are per browser; folders and icon positions are shared. The canvas is meant for desktop-sized viewports.

## Develop and install

From this repository, install package dependencies with `npm ci --prefix prototypes/desktop-canvas-prototype`. The dedicated Canvas Desktop Prototype workflow runs checks remotely. The build script uses the repository's pinned SDK builder; bb's Git/path installer bundles the same entry points automatically.

Install only into an isolated development bb first. Production installation is a separate user action:

```sh
bb plugin install git:https://github.com/brsbl/bb-plugins.git@<tested-commit> --subdirectory prototypes/desktop-canvas-prototype --yes
```

Uninstall `desktop-canvas-prototype` to remove its page. Desktop folders and icon positions are kept in the plugin's own storage; sections it creates or renames are ordinary bb sections, and view options are the sidebar's (Thread List's) own preferences, read and written through its public RPC. Requires bb with `experimental_NewThreadComposer`, `ThreadChat`, sidebar data hooks and nav panels. Vendored button and motion primitives come from bb core's `packages/shared-ui/src`; the SDK and build dependencies are the repository's pinned releases.
